Test Api Person UDLAZ


el proyecto fue creado en net core 6.0

dependecias para instalar en el proyecto son:
Install-Package Microsoft.EntityFrameworkCore -Version 6.0.36
Install-Package Microsoft.EntityFrameworkCore.Tools -Version 6.0.36
Install-Package Microsoft.EntityFrameworkCore.Design -Version 6.0.36

Microsoft.EntityFrameworkCore 6.0.36
Microsoft.EntityFrameworkCore.SqlServer 6.0.36
Microsoft.EntityFrameworkCore.Tools 6.0.36
Microsoft.EntityFrameworkCore.Design 6.0.36

para realizar la migracion a la base de datos de SQLSERVER 
en el terminal de administracion de paquetes nuget en la consola 
ejecutamos
los comandos son :
>Add-Migration InitialCreate
>Update-Database
al ejecutar los dos comando 
se migra la base de datos
